AlmaChess – Stresstest mit Artillery

Open-Loop-Belastung: feste Ankunftsrate pro Sekunde, Server kann nicht aufholen.

Kurzfassung: Bei 30 Anfragen/Sekunde läuft alles glatt. Bei 75 Anfragen/Sekunde reißen 22 % der Anfragen ins 10-Sekunden-Timeout. Ab 150/s sind über die Hälfte verloren, bei 500/s schaffen nur noch 11 % eine Antwort. Artillery deckt damit eine härtere Grenze auf als der k6-Stresstest – siehe Vergleich am Ende.

6. Artillery vs k6 – warum sind die Zahlen so unterschiedlich?

Beide Tools fahren dieselbe API gegen dieselben Daten. Trotzdem fällt der Knee-Point bei Artillery viel früher. Der Unterschied liegt im Lastmodell:

Closed-Loop (k6): N Worker, jeder wartet auf seine eigene Antwort, bevor er die nächste schickt. Wird der Server langsam, schicken alle seltener. Tatsächliche Last ≤ Server-Kapazität.

Open-Loop (Artillery): N neue Anfragen pro Sekunde – unabhängig davon, ob der Server bereit ist. Wird der Server langsam, stauen sich Anfragen, bis es ins Timeout läuft. Tatsächliche Last = was ausgemacht wurde.

Beide Sichten sind richtig, aber sie messen Verschiedenes:

  • k6 beantwortet: „Wie viele dauerhaft verbundene Clients kann ich bedienen?" → 75 gehen gut, 150 brechen.
  • Artillery beantwortet: „Wie viele Anfragen pro Sekunde verkraftet der Server, ohne dass Anfragen verloren gehen?" → 30/s sind sicher, ab 75/s gehen welche verloren.

Für Production-Capacity-Planung ist Artillerys Antwort die ehrlichere: echte Nutzer warten nicht, sie laden die Seite neu oder gehen weg.

7. Reproduktion

Voraussetzung: Stack läuft (docker compose up -d) und Mongo ist mit 10 k Spielen geseedet.

$perfArt = (Resolve-Path "perf\artillery").Path
$perfRes = (Resolve-Path "perf\results").Path
docker run --rm `
  -v "${perfArt}:/scripts" -v "${perfRes}:/out" `
  artilleryio/artillery:latest run `
  --output /out/artillery-stress.json `
  /scripts/persistence_stress.yml

Laufzeit: ~3 Minuten. Erzeugt perf/results/artillery-stress.json und artillery-stress.txt.

Skript: perf/artillery/persistence_stress.yml + stress_helpers.js. Rohdaten: perf/results/artillery-stress.{txt,json}.
